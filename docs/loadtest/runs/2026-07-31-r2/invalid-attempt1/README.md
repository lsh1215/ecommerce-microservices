# 무효 — 시드 실패 상태에서 측정됨 (읽지 말 것)

MySQL 자격증명 오류(`sa/1234` vs 실제 `sa/changeme`)로 시드가 적재되지 않은 채 측정이 진행됐다.
상품 데이터가 없어 34,977건 전부 4xx로 거절됐고, 2xx는 0건이다. 락 경합을 전혀 측정하지 못했다.

유일하게 유효한 신호는 CPU 스로틀 지표다(환경 검증용):
  cpu_throttled_ratio_order   = 0.0027
  cpu_throttled_ratio_product = 0.0003
→ 2000m 프로파일에서 스로틀이 사실상 없음을 확인. 이후 런의 수치는 코드를 잰 값이다.
